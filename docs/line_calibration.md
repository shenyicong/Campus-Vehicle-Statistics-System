# 虚拟线标定与假跨线抑制

## 问题 1：默认 `LINE_Y = 0.5` 可能落在空白区

`config.LINE_Y` 默认 0.5（画面正中）。但固定机位俯拍画面上半部通常是
天空 / 建筑 / 树，车辆全部集中在下半部。三段俯拍视频实测：

| 视频 | 车辆 cy 最小值 | cy 中位 | 默认线 0.5 是否有效 |
|---|---|---|---|
| `dl (2).mp4`（高架俯拍） | 0.404 | 0.694 | 处于分布边缘，几乎无跨线 |
| 安宁区街道俯拍 | **0.591** | 0.727 | ❌ 完全在空白区，必然计 0 |

所以**换视频后必须重新标定**，不能沿用 0.5。

## 标定工具

```bash
python tools/calibrate_line.py --video <视频> --frames 120
```

输出车辆中心 cy 的分位数、跟踪 ID 数、连续帧位移统计，以及
0.50~0.90 各候选虚拟线的「向下 / 向上」跨线次数，并自动判断：

- 当前虚拟线是否低于 cy 最小值（落在空白区）；
- 车流是否近似静止（连续帧 `|dy|` 中位 < 0.002）。

标定后用环境变量覆盖，无需改代码：

```bash
set CAMPUS_LINE_Y=0.68
set CAMPUS_VIDEO=D:\path\to.mp4
python main.py
```

## 问题 2：静止车流的框抖动会制造假过车

标定工具发现两段竖屏视频的连续帧位移中位数都是 **0.0000**
（延时 / 静帧短视频，车辆排队几乎不动），但把虚拟线放到 0.80 时，
`main.py` 仍会报出 **11 次进 / 9 次出** —— 这些全是检测框上下抖动
反复穿过虚拟线造成的，不是真实过车。

### 修复：`MIN_TRACK_MOVE` 最小净位移门限

`counter.py` 为每条轨迹维护一个参考 y（首次出现或上次计数时的位置），
只有当 `|当前 cy − 参考 y| >= MIN_TRACK_MOVE`（默认 0.03，占画面高度比例）
时才允许判定跨线；计数后重置参考点，避免同一轨迹重复计数。

### 验证（安宁区视频，120 帧，`LINE_Y = 0.80`）

| 配置 | 进 | 出 | 说明 |
|---|---|---|---|
| 抑制关闭 (`CAMPUS_MIN_MOVE=0`) | 11 | 9 | 20 次假过车 |
| **抑制开启（默认）** | **1** | **0** | 假过车基本消除 |
| 抑制开启 + 工具推荐线 0.68 | 1 | 1 | 同上 |

回归：合成测试视频（车辆持续移动）仍为 **进 4 / 出 3**，真实过车未被误杀。

## 使用建议

1. 拿到新视频先跑 `calibrate_line.py`，确认 ① 虚拟线在车辆分布内 ② 车流有持续位移。
2. 车流静止的视频**不要**用来演示进出计数，即使调线能"造出"数字。
3. 理想素材：固定机位、连续无剪辑、镜头不摇动、车流持续通过，
   白天 2–3 分钟即可（如校门口三脚架俯拍）。
4. 车流很慢时可降低 `CAMPUS_MIN_MOVE`（如 0.02）；框抖动严重可提高到 0.05。
